# Bug Report: demo fly does not smell food, does not eat, flips direction, ignores danger

**Type**: Implementation defect (four code bugs) + spec gap (ADR 010 D27, D32 partly unimplemented)
**Severity**: High (R1 and R2 cannot pass)
**Feature**: Demo forager (`017-demo-forager`, ADR 010)
**Reported**: 2026-10-17
**Status**: Patched
**Patched**: 2026-10-17

## Description

Reported in the running app, `world/world-forager-demo.json`:

1. the fly does not recognise food odour;
2. the fly does not eat and does not recover energy;
3. the fly suddenly jumps to a random direction;
4. there is no visible action on danger;
5. the fly is always drawn pointing from bottom to top.

## Root causes (measured, scratch diagnostic on the closed loop, 6 flies × 3,000 ticks)

| # | Symptom | Root cause | Evidence |
|---|---|---|---|
| A | 1, 2 | `fly-world.js` took the wide-I/O branch only for `"v2"`. A `"v3"` world read the v1 `flies.stimulus.objects` list, which it does not have, so it had **no stimulus cells**: no flowers, no food odour, no taste, nothing to eat | Both demo worlds: 10 and 5 edibles, 0 stimulus cells. `odour-food` input 0.000 on every tick |
| B | 2 | The body layer reused v1/v2 `canEat`, which needs `speed < eatSpeed` (0.5). W12 always walks at ≥ `baseSpeed` (0.6), so eating was impossible. D30 has no speed gate | Minimum speed 0.60 on every fly |
| C | 2 | `feedThreshold` 0.5 was copied from v2, where `feed` is a 0–1 output. In v3 it is `r̄ − rest` in spikes per neuron per tick; MN9 reaches 0.5 about 1 % of ticks | Feed probe below |
| D | 3 | Backing up set `heading += π` **every tick** of the 10-tick run, flipping the fly 180° each tick | 151 of 600 ticks turned > 60° in one tick |
| E | 3, 4 | Named pools (`alarm`, `feed`, `forward`, `backward`) were read raw, not smoothed (D29: τ = 3). One coincident spike in a 2–4 neuron pool reads 0.5–1, which starts backing up and escape on noise | Escapes and backups with no stimulus |
| F | 1, 4 | No readout pool for food, danger or heat: D27 limits candidates to DNs, and no DN responds (C1 finding). `alarm` held only the 2 DNp01 neurons | Old decoder: `drive.taste-mouth`, `feed`, `forward`, `backward`, `alarm` only |
| G | — | D32 half-implemented: the threshold ramp existed, but `odour-food` `gainMin` stayed at the snapshot's 0.5 (ADR: 0), and `forager-arms.mjs` never passed `flies.modulators` to the brain | Sated brain still received food odour at gain 0.5 |
| H | — | The world ran `synapticScale` 15 / `baselineCurrent` 0.03, but the decoder's rest rates were measured at 5 / 0.04 | `decoder.lif` vs `flies.brain.lif` |
| I | 5 | `renderer.js` drew the sprite unrotated. Physics and sensing already used the heading | — |

## Fix

| # | Change | Files |
|---|---|---|
| A | `"v3"` takes the wide-I/O branch | `public/js/fly/fly-world.js` |
| B | D30 as written: eat when on stock and `feed ≥ feedThreshold`; a feeding fly stands still for the tick | `public/js/fly/body-layer.js` |
| C | `feedThreshold` 0.1, from the feed probe | both demo worlds, `contracts/world-config-v3.md` |
| D | Backing up walks backwards and keeps the heading | `public/js/fly/body-layer.js` |
| E | Every pool's rate is smoothed (τ = 3) before rest is subtracted | `public/js/fly/decoder.js`, `contracts/decoder-v1.md` |
| F | ADR 010 Amendment A1: C2 candidates are every non-input neuron; `alarm` reads `drive.odour-danger` when it exists; `escape.threshold` 0.4 from the alarm probe. C2 re-run with D27's default gates | `decoder-engine.mjs`, `profiles/demo-v3.mjs`, `decoder.js`, `forager-brain-wide.decoder.json`, ADR 010, `contracts/decoder-v1.md` |
| G | `flies.modulators.<id>.gain` override; demo worlds set `hunger.gain` [0, 1.5]; v3 arms receive `flies.modulators` | `fly-brain-v1.js`, `validate.js`, `fly-config.js`, `forager-arms.mjs`, both demo worlds, `contracts/world-config-v3.md` |
| H | C2 re-run at the world's own LIF block (15 / 0.03) | `forager-brain-wide.decoder.json` |
| I | Sprite rotated by `heading + π/2` (art faces −y, heading 0 is east) | `public/js/render/renderer.js` |

Tests: `tests/demo-forager-bug001.test.mjs` (one per root cause, A–G).

## Not fixed (findings, recorded)

- **Tropotaxis is mostly unavailable.** Side-selective neurons are rare (food 3 + 6, danger 2 + 3; under D27's
  minimum of 5 a side). The food field is stepped per tile and the antennae sit 0.5 tiles apart, so both often
  sample one cell. Approach rests on klinotaxis.
- **Klinotaxis is weak at the shipped locomotion values.** `wander` 0.4 rad/s gives near-straight walks, and
  `castMax` 1 means a rising avoid trend cannot increase turning, against W13's own "rising avoid → turn more".
  These are body-layer config values that no stage calibrates; ADR 010 Part H removed world-stage sweeps.
- **Danger covers half of the sketch map.** 858 of 1,730 walkable cells have danger > 0 (the ragged border is all
  edge forest).
- `tests/activity.test.mjs` fails (6 tests) on the uncommitted `activity.js` timing change, which predates this fix.
