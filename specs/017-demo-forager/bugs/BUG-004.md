# Bug Report: the fly turns instantly and jumps to a new position

**Type**: Implementation gap (body physics)
**Severity**: Medium (visible in every run; escape behaviour)
**Feature**: Demo forager (`017-demo-forager`, ADR 010)
**Reported**: 2026-10-17
**Status**: Patched
**Patched**: 2026-10-17

## Description

The fly makes immediate turns and jumps to a new position. This cannot be fixed in the brain; steering in the world
should be smooth, as real motors are.

## Root cause

The v3 body applied every command at once:
- an escape set the heading in one tick (`heading + π` with no danger side pool) and moved the fly
  `escape.distance` = 1.5 tiles in one tick (`applyEscape`); a walking step is about 0.03 tiles;
- the world's `flies.body.turnRate` was not read by v3, so nothing bounded a heading change.

Measured (sketch map, 6 flies × 3,000 ticks): largest turn 3.14 rad per tick, largest step 1.5 tiles, 2–30 steps
over 0.25 tiles per fly.

## Fix

ADR 010 Amendment A4: a motor stage, `flies.body.motor: { maxTurnRate, escapeTurnRate, maxAccel, sprintSpeed }`
(`body-layer.js` `motorStep`). The reflex laws give a target heading and speed; the body follows them within the
limits. An escape is a turn-and-sprint over `escape.distance`, with the brain's trigger, threshold and cooldown
unchanged. Demo worlds: 4 rad/s, 15 rad/s, 12 tiles/s², 3 tiles/s. Files: `body-layer.js`, `fly-config.js`,
`fly-host.js`, `forager-arms.mjs`, `validate.js`, both demo worlds, `contracts/world-config-v3.md`, ADR 010.

Tests: `tests/demo-forager-bug001.test.mjs` (BUG-004 section).

## Result

Both maps, 6 flies × 3,000 ticks: largest turn 0.75 rad per tick, largest step 0.17–0.24 tiles, no step over 0.25.

Calibration seeds 6–8, 1,500 ticks, shipped decoder:

| Map | Motor | Find | Ticks in danger | Ticks in heat | K4 (exit within 20 ticks) |
|---|---|---|---|---|---|
| sketch | none | 38.9 % | 46.8 % | 6.3 % | 41.7 % |
| sketch | 4 / 15 / 12 / 3 | 50.0 % | 39.7 % | 14.8 % | 37.5 % |
| tilemap | none | 22.2 % | 27.7 % | 2.5 % | 63.2 % |
| tilemap | 4 / 15 / 12 / 3 | 22.2 % | 3.9 % | 5.7 % | 48.3 % |
| (random walk) | — | 55.6 % / 38.9 % | 62.0 % / 66.2 % | 15.0 % / 7.4 % | — |

## Trade-offs (recorded)

- K4 falls: a turn-and-sprint leaves a danger ring later than a 1.5-tile teleport, while total time in danger falls.
- Heat time on the sketch map rises to the random walk's level (6.3 % → 14.8 %).
- W12's surge multiplies speed after the `maxSpeed` clamp, so a walking fly can briefly exceed `sprintSpeed`. It ramps
  through the motor stage, so it is not a jump.
