# Bug Report: Forager brain shows a sphere of points in the app, but a proper shape in the brain inspector

**Type**: Spec conflict
**Severity**: Medium
**Feature**: Hungry Forager Brain (`008-hungry-forager-brain`)
**Reported**: 2026-10-05
**Status**: Patched
**Patched**: 2026-10-05
**Decision**: Follow 004. Soma-less neurons are not drawn in the app; the view states the count.
**Fix**: T104–T106 done (`layout.js` `somaPositions`, `fly-host.js`, `panel/model.js`, `neuron-map.js`). T107 (browser check) open.

## Description

Loading the forager world (`public/world/world-forager.json`, snapshot `brains/forager-brain.brain`) shows the
"Brain activity" point cloud in the fly panel as a sphere of points. The same `forager-brain.brain` file, opened in
the brain inspector (`public/brains/`), shows the brain's shape.

The data is the same. The two views disagree on what to draw for a neuron that has no soma position:

- **Brain inspector** (`public/brains/js/model.js` `drawableNeurons`, `public/brains/js/scene.js` `setBrain`):
  draws only neurons with a soma. Neurons without one are left out, as spec 004 requires.
- **App** (`public/js/brain/layout.js` `neuronPositions`, used by `public/js/fly/fly-host.js` `positionsFor` and
  `public/js/ui/panel/sections/neuron-map.js`): places every neuron without a soma on a unit sphere from a seeded PRNG.
  Spec 006 (`research.md` R6, `tasks.md` T039 and T046) decided this for those neurons.

In `forager-brain.brain`, 964 of 3408 neurons (28%) have no soma. Those 964 points all lie at radius 1.000 from the
centre. That is the sphere the user sees. The 2444 soma neurons sit inside the same unit cube and are not hidden, but
the fixed-radius shell dominates the picture.

The other two reference brains have almost no soma-less neurons (`smallest-functional-brain.brain`: 0 of 11;
`antennal-lobe-brain.brain`: 1 of 35). That is why the sphere fallback did not show up before this feature. The forager
brain is the first snapshot where it does.

## Artifact Traceability

### spec.md
- **Affected user story**: None directly. The forager spec (008) defines no requirement for how the brain is drawn.
- **Affected requirements**: None in 008. The conflicting requirements are in 004 and 006 (see below).
- **Gap identified**: 008 does not say whether a forager brain's point cloud in the app must match the brain inspector.
  Because the forager brain is the first snapshot with many soma-less neurons, the existing rules in 004 and 006 now
  contradict each other on it.

Conflicting rules from other features:
- `004-brain-point-cloud-inspector/spec.md`, edge cases: "A neuron has no soma position in the dataset. ... The viewer
  does not draw that neuron or its edges, and it states how many were left out."
- `006-fly-status-panel/research.md` R6: "Neurons without a soma are placed on a seeded sphere ... Toy brains have no
  soma and use the seeded sphere for all neurons."

### plan.md
- **Affected sections**: 008 has no plan section for the fly panel's point cloud. The relevant plan sections are in
  `006-fly-status-panel/plan.md` (`layout.js`: "soma → unit cube, seeded fallback (pure)").
- **Impact**: 008 needs a decision on whether the app keeps the 006 fallback for connectome-style brains with missing
  somas, or follows 004 and skips them. The plan for 008 would then state that decision for the forager brain.

### tasks.md
- **Affected tasks**: None in 008. The behaviour traces to completed 006 tasks:
  - T039 `public/js/brain/layout.js` `neuronPositions`: soma-less neurons on a seeded sphere.
  - T046 `public/js/main.js` and the panel use `neuronPositions`.
- **False completions**: None. T039 and T046 match 006 R6 as written. The problem is that 006 R6 conflicts with 004.
  Reopening them is a decision for the user, not a defect in the code.
- **Missing tasks**: Depending on the decision, one of:
  - (a) Keep the sphere fallback, but draw soma-less neurons as a visibly separate, dimmed group, and state the count
    in the panel, as 004 does for the inspector.
  - (b) Follow 004: skip soma-less neurons in the app's point cloud and state how many were left out.
  - In both cases, add a test that the app's point cloud for `forager-brain.brain` has the same drawn set as the inspector.

## Root Cause Analysis

Spec conflict, with the forager brain as the first case that exposes it. Two features made different choices for
neurons without a soma:

- 004 chose to omit them (the inspector).
- 006 chose to place them on a seeded sphere (the app), and that choice was made when the reference brains had none.

The code follows each spec. No implementation error was found. The positions were checked by running
`neuronPositions` on `forager-brain.brain`: soma neurons span roughly ±0.44 × ±0.51 × ±1 in x, y, z, and every
soma-less neuron has radius exactly 1.0.

Not verified: whether `sizeAttenuation: true` with `POINT_SIZE` 0.07 in the app's `point-cloud.js`, against the
inspector's fixed-pixel `sizeAttenuation: false`, adds to the visual difference. It is a possible secondary contributor
and needs a look in the browser.
