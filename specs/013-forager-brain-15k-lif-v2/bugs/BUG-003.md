# Bug Report: v2 calibration grid is centred on a synapticScale 4× too high and never searches the LIF mechanisms that make ignition gradual

**Type**: Spec gap (ADR 006 L11's starting value, resolving ADR 006 Q1) + Implementation drift (`profiles/v2.mjs`'s
grid omits mechanisms ADR 005/ADR 006 already named and wired, with no stated reason to leave them out)
**Severity**: High
**Feature**: Cautious Forager Brain (15K, LIF v2) (`013-forager-brain-15k-lif-v2`)
**Reported**: 2026-10-11
**Status**: Fixed; held-out verdict still blocked on a fresh calibration pass against the widened grid
**Patched**: 2026-10-11
**Fixed**: 2026-10-11 — ADR 006 gained `### A6` under `## Amendment 2026-10-11`, correcting `synapticScale`'s
derivation and resolving Q1 for this row; `profiles/v2.mjs`'s `L11` constant, `axes`, `classifyScan` and
`brainOf()` updated to match and widened with `inhibitoryScale`/`adapt`/`thresholdJitter`; `calibration.md`'s
"Next step" guidance updated. Unit-tested in new `tests/calibrate-profile-v2.test.mjs` (5 tests); `npm test`:
553/559 passing (the 6 failures are the pre-existing, feature-unrelated `tests/activity.test.mjs` failures).
No new `/microfly-calibrate` search has been run against the widened grid — per AGENTS.md this must happen in a
separate session; the user has been told to run it there.

## Description

Both defects sit upstream of [BUG-002](BUG-002.md)'s gate fixes: BUG-002 corrected how `--stage=auto` *scores* a
grid point; this bug is about the grid itself — the wrong centre and missing axes explain why the corrected scoring
still only turns up an ignition cliff (`calibration.md`'s "Update 2026-10-11" sections, re-scored 45/342 passing,
34 robust, all clustered right at the edge of silent-vs.-ignited, none yet checked against `brake`/`feed`/`settle`).

**1. ADR 006 L11's `synapticScale` starting value (`adrs/006-cautious-forager-brain-15k.md:283`, `0.04`) is
derived with the wrong unit and is about 4× too high.** L11 cites Shiu et al. 2024: "0.275 mV per synapse against
a 7 mV rest-to-threshold gap" → `0.275 / 7 ≈ 0.0393`, rounded to `0.04`. But Shiu et al.'s own model
(github.com/philshiu/Drosophila_brain_model, `model.py`) is `dv/dt = (v0 − v + g)/t_mbr` with `g += w` on a
synaptic event, `g` itself decaying with its own time constant `τ = 5 ms`, and `t_mbr = 20 ms`. A synaptic weight
`w` of 0.275 mV is not the net charge delivered to `v` — it is the step added to `g`, which then drains into `v`
scaled by `1/t_mbr` over its own `τ`-ms decay. The net charge actually delivered per synaptic event is
`w · τ / t_mbr ≈ 0.275 × 5 / 20 = 0.06875 mV`, not `0.275 mV`. Against the same 7 mV gap: `0.06875 / 7 ≈ 0.0098`,
not `0.0393`. L11's `0.04` is **≈ 4.08× the corrected value**.

   This matters because `lif-v1.js`'s own synaptic filter (`public/js/brain/lif-v1.js:205`,
   `syn[i] = syn[i] * decaySyn + input[i] * (1 - decaySyn)`) is an exponential moving average with **unit area**:
   summed over all future steps, a single arrival's total contribution to `drive` equals the arrival itself,
   regardless of `tauSyn`. So in this core, unlike Shiu's two-time-constant `g`/`v` pair, `synapticScale` already
   *is* the total charge per synapse — there is no second division by a membrane time constant left to apply. The
   `0.04` quoted in L11 reproduced Shiu's `w` (the pre-decay step) without finishing Shiu's own conversion to net
   charge, then divided by 7 mV as if it already were net charge. This is exactly the check ADR 006's own Q1 asks
   for and marks as not yet done ("confirm each before Gate B," `adrs/006-cautious-forager-brain-15k.md:450`).

**2. `profiles/v2.mjs`'s grid searches only five parameters, leaving out every mechanism that makes a LIF network's
ignition transition gradual instead of a cliff — despite those mechanisms already existing in `lif-v1.js`, off by
default, specifically for this purpose.** `axes` (`.claude/skills/microfly-calibrate/scripts/profiles/v2.mjs:56–62`)
varies only `synapticScale`, `tauSyn`, `inputRateHigh`, `stepsPerTick` and `groupGain`. Left untouched at their
all-off defaults for every one of the 342+ grid points scored so far:

   - **Adaptation** (`tauAdapt`/`adaptStep`, ADR 005 L2, `lif-v1.js:17–18`): spike-driven threshold fatigue that
     caps runaway activity after the first few spikes. The shipped v1 brain already ships non-zero values for
     this mechanism (`tauAdapt: 20, adaptStep: 0.05` — ADR 006 Annex A6's cost table, `adrs/
     006-cautious-forager-brain-15k.md:703`, uses exactly these as its baseline settings), so there is dataset-
     brain precedent for turning it on, not just a hypothetical.
   - **Threshold heterogeneity** (`thresholdJitter`, ADR 005 L3, `lif-v1.js:19`): per-neuron threshold spread,
     which staggers when different neurons in the same pool cross threshold instead of all doing so at once.
   - **Membrane noise** (`noiseAmplitude`/`noiseBulkScale`, ADR 005 L7/L7′, `lif-v1.js:22–23`): the mechanism ADR
     005 Annex B.3 and this ADR's own Context point 4 already discuss for exactly this brain's rest-regime
     problem.
   - **Inhibitory gain** (`inhibitoryScale`, ADR 005 L8, `lif-v1.js:24`): a multiplier on every negative edge
     weight, the direct lever for strengthening the network's own recurrent inhibition relative to its excitation.

   These are the standard remedies for the measured symptom. `calibration.md`'s "Update 2026-10-11" sections
   describe exactly a noise-free, excitation-dominated LIF with no adaptation and no threshold spread: "a cliff,
   not a ramp" (line 88) — at `synapticScale 0.0025` every non-`al` region is silent; at `≥ 0.003` everything
   ignites together. At the single best point found across five runs (`synapticScale 0.006, groupGain.al 0.4`,
   `runs/v2-auto-algain-fine-20261011/auto.json`), food odour (0.5) raises `central`'s rest activity from
   **0.0530** to **0.2979** — rest and odour driving the *whole* network roughly together, not a region-local
   response (confirmed directly against the stored checkpoint: `rest.central: 0.05300199326863385`,
   `odour.central: 0.29793789279918126`). A global excitatory scale with no counterbalancing mechanism will always
   look like this: too low and everything is silent, too high and everything is saturated, because there is
   nothing in the model that damps runaway recurrent excitation locally. None of the four parameters above has
   ever been given a non-default value in a `--stage=auto` run for this brain.

## Root Cause Analysis

1. **L11's conversion stopped one step short of Shiu et al.'s own model.** The ADR quotes "0.275 mV per synapse"
   straight from the paper's reported synaptic weight without re-deriving what that weight means inside Shiu's
   two-variable (`g`, `v`) integration, where a weight is a step on an intermediate decaying variable, not a
   direct addition to membrane potential. ADR 006's own text flags this honestly (Q1: "must be checked against it
   before calibration starts") but no checking happened before the grid in `profiles/v2.mjs` was built around it —
   the grid treated L11's value as ground truth rather than as the open question the ADR itself says it is.
2. **The calibration profile's axis list was built around what ADR 006's Calibration protocol text literally
   enumerates** (`synapticScale ×{0.5,1,2,4}`, `tauSyn {2,5}`, `input.rate[1] {0.08,0.15,0.3}`, `stepsPerTick
   {5,10}`, `adrs/006-cautious-forager-brain-15k.md:380–381`), not around the full set of off-by-default
   mechanisms `lif-v1.js` already implements for this exact problem. The protocol text itself never mentions
   `inhibitoryScale`/`tauAdapt`/`adaptStep`/`thresholdJitter` as search axes — it inherited ADR 005's staged A1/A2/B
   structure (which these mechanisms were built for) without carrying the mechanisms themselves into the stated
   starting grid.
3. **Five `--stage=auto` runs reading a cliff as a brain-level finding, not a search-coverage gap.** Both
   `calibration.md`'s "Finding" (pre-BUG-002, now retracted) and the post-BUG-002 "45/342, 34 robust" result were
   read as characterising the brain's own dynamics ("al looks upstream of the rest of this circuit's activity,"
   `calibration.md:117`). Every one of those runs varied the same five parameters from the same (wrong) centre; a
   cliff between "everything silent" and "everything ignited together" is the expected signature of a model with
   no adaptation, no threshold spread and no tunable inhibition — the search never had the mechanism needed to
   produce anything else.

     `synapticScale`'s derivation to `w · τ / t_mbr ÷ 7 mV ≈ 0.0098`, note the extra conversion step L11 skipped,
     and mark Q1 resolved for this row (leaving `tau`, `refractorySteps`, `tauSyn` as previously stated — not
     re-derived here).

     place of the current `[0.002, 0.005, 0.01, 0.02]`; add `inhibitoryScale: [1, 1.5, 2, 3]`, `tauAdapt: [50, 100,
     200]` with a paired `adaptStep` axis, and `thresholdJitter: [0, 0.1, 0.2]`; pass all four through
     `brainOf()`'s `lif` config object.

     widened axes instead of the uncorrected `synapticScale 0.005` narrowing it currently proposes.
