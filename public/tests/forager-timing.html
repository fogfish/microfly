Forager timing (ADR 003 Gate B)

Six v1 flies from world/world-forager.json run in their own workers for 60 seconds of visible time. The page reports, per fly, the mean and 95th percentile of the interval between ticks, and the stepsPerTick used. The brain runs in the worker, so the interval is the timing a visitor sees.

Open this page from the static server root with ?seconds=60 (default 60).
